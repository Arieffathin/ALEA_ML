# Aksara Learning App  

---

## 📖 Overview  

Indonesia has a rich diversity of traditional scripts that are vital to its cultural identity, including **Sunda**, **Bali**, **Lampung**, and **Pegon** scripts. Unfortunately, knowledge and usage of these scripts are declining due to limited resources and exposure in modern society.  

**Aksara Learning App** is an interactive web-based platform that helps users detect and classify these four traditional scripts from uploaded images. The app leverages **YOLOv8**, a cutting-edge machine learning model for object detection, integrated with a **Flask API**, and modern frontend technologies — delivering an engaging and educational tool for script recognition and preservation.  

---

## 🎯 Purpose  

The Aksara Learning App was designed to:  

- Assist users in identifying **Sunda**, **Bali**, **Lampung**, and **Pegon** scripts using AI-powered detection  
- Encourage cultural preservation through innovative technology  
- Provide accessible learning tools for Indonesia’s traditional scripts  
- Demonstrate the role of AI in supporting cultural sustainability  

This project covers the **entire pipeline**: from **data collection, model training, API development, to deployment**, as a real-world AI solution for cultural heritage preservation.
